# Motivation Hackathon

En prototype fra en hackathon: en motivasjonsside der brukere kan registrere seg, velge personlige egenskaper og arbeide med oppgaver. Frontenden bruker HTML, CSS, JavaScript og jQuery Mobile, med PHP og MySQL på serversiden.

## Innhold

- `App/`: nettsider, brukerregistrering, innlogging, egenskaper, oppgaver og statiske ressurser.
- `Database/tables.sql`: SQL-oppsett.

## Åpne prosjektet

Bruk et lokalt PHP/MySQL-miljø, undersøk SQL-skjemaet og tilpass databaseoppsettet i `App/dbsettings.php`. Koden stammer fra et eldre PHP-miljø og kan kreve tilpasninger. Den opprinnelige README-en sier uttrykkelig at fungerende database og kjørbar versjon er usikkert; denne merknaden er bevart nedenfor.

Repoet er omdøpt fra `Startup` til `motivation-hackathon` for å beskrive formålet.
